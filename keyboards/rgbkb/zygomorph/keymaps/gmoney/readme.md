## Build and Hardware

From QMK MSYS at the firmware root:

```sh
qmk compile -kb rgbkb/zygomorph/rev1 -km gmoney
```

This migrated keymap retains the fork's D5 fourth matrix column and B7 RGB wiring. Shared configuration and build options are in `keyboards/rgbkb/zygomorph/common/fork_config.h` and `fork_rules.mk`. Both encoders retain counterclockwise volume-up and clockwise volume-down bindings. EEPROM handedness must be configured for each half.

For an OLED-equipped board, add `-e OLED_ENABLE=yes`. The modern OLED driver uses the original font and displays layers and lock status; the debug console is disabled in OLED builds to keep the firmware within the flash limit.
